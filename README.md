# 基于YOLOv8的行人摔倒智能识别与报警系统

——第十九届大学生科研训练计划（SRTP）项目

## 命题Intro

> 跌倒是65岁以上老年人因意外伤害死亡的首要原因。传统依赖人工巡查或可穿戴设备的方式存在效率低、依从性差等问题，而基于计算机视觉的方法具有非接触、覆盖广、成本低等优势。本项目旨在开发一个纯软件解决方案：基于YOLOv8目标检测模型与Web界面，用户可上传图片、视频或连接摄像头，系统自动识别画面中是否有人摔倒，用标注框标出跌倒位置并触发声音报警，为养老监护和智能安防提供低成本、易部署的摔倒检测工具原型

> |    所属学科    | 所属学院 | 相关学科 |             关键词             |
> | :------------: | :------: | :------: | :----------------------------: |
> | 计算机类(0809) | 本科生院 |          | `YOLOv8` `摔倒检测` `目标检测` |

> **预期目标**
> 实现一个可运行的软件原型，支持图片、视频、摄像头三种输入方式的行人摔倒检测；掌握Python环境配置和YOLOv8模型的基本使用；能加载预训练权重文件，对输入图像进行推理并输出检测结果；对于检测到的摔倒行为，能在画面中用标注框标出并显示置信度；开发Web界面，支持用户上传文件、实时预览检测结果；当检测到摔倒时，界面触发声音报警提示。

> **预期成果**
> ①可运行的软件原型；②结题报告。

### 前端

> [![node](https://img.shields.io/badge/node-v26.3.0-5FA04E?style=flat-square&logo=nodedotjs&logoColor=white)](https://nodejs.org/)

1. 进入前端工作目录

```sh
cd frontend
```

2. 安装所需依赖

```sh
npm install
```

3. 开始调试

```sh
npm run dev
```

默认为http://0.0.0.0:5501
